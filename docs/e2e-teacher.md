## เตรียม

   (ล้างเฉพาะสิ่งที่บัญชีนี้บันทึกในเบราว์เซอร์นี้ ข้อมูลตั้งต้นของนักเรียนไม่ถูกลบ)

> **รู้ก่อนทดสอบ:** คะแนนความเสี่ยงมาจากข้อมูลตั้งต้น ไม่ขยับตามสิ่งที่ครูบันทึก (ระบบจริงจะขยับเมื่อข้อมูลการมาเรียนใหม่เข้ามา)
> สถานการณ์ A จึงจบที่ "ช่วยเหลือครบวงจร" ส่วนการ "ปิดเคส" ทดสอบในสถานการณ์ B กับเด็กที่ข้อมูลดีขึ้นแล้ว
> การส่งต่อเป็น **โหมดภายใน** — ยังไม่ต่อระบบหน่วยงาน ครูส่งเรื่องทางช่องทางปกติ (หนังสือ/โทร/พบตัว/LINE) แล้วกด **อัปเดตความคืบหน้า** เมื่อได้ข่าวจากหน่วยงาน

## สถานการณ์ A — เด็กมีปัญหาใหม่ ช่วยตั้งแต่ต้นจนส่งต่อได้ผล

**เด็ก:** ฮาฟิซ ยูโซะ (STD-0661) ม.5 · ขาดเรียนติดกัน 8 วัน · ผู้ปกครองตอบช้า · ยังไม่เคยเยี่ยมบ้าน · ยังไม่มีแผน

| # | ทำ | ต้องเห็น |
|---|---|---|
| A1 | **เคสของฉัน** | ผู้ช่วย AI บอกจำนวนเด็กที่ควรตามวันนี้ |
| A2 | **การช่วยเหลือ** | การ์ด "วันนี้ต้องติดตาม N เคส" · ฮาฟิซอยู่กลุ่ม **เกิน SLA** เหตุผล "เกิน SLA 16 วัน — ไม่มีการอัปเดต 23 วัน" · ถัดไป "ติดต่อผู้ปกครองภายในวันนี้" |
| A3 | กด **ดูเคส** ที่ฮาฟิซ → ลิงก์ **ข้อมูลเด็กรายบุคคล** (หรือเปิดเมนูข้อมูลเด็ก แล้วเลือกฮาฟิซ) | หัวการ์ด: เกจ 48 · "สถานะ: รอผู้ปกครอง" · แถบ **สิ่งที่ต้องทำต่อ: ติดต่อผู้ปกครองภายในวันนี้** |
| A4 | แท็บ **ดูแลช่วยเหลือ → สิ่งที่ครูพบ** กด **+ นักเรียนขาดเรียนต่อเนื่อง 8 วัน** แล้วกด **+ เพิ่มสิ่งที่พบ** พิมพ์ `ไม่มีค่ารถมาโรงเรียน แม่ตกงาน` → บันทึก | สิ่งที่พบ 2 ข้อ · **แนวทางที่อาจช่วยได้** ข้อ 1 เปลี่ยนเป็น **"หาทุนค่าเดินทาง"** เหตุผล "ครูบันทึกว่ามีปัญหาค่าเดินทาง" |
| A5 | แถบสิ่งที่ต้องทำต่อ → **บันทึกการติดต่อ** → เลือก **ติดต่อไม่ได้** → บันทึกผล | "✓ บันทึกการติดตามแล้ว" และถาม "ทำอะไรต่อ" |
| A6 | **นัดติดตามครั้งถัดไป** → เลือก **เยี่ยมบ้าน** → บันทึกนัด | สิ่งที่ต้องทำต่อ = **"รอเยี่ยมบ้านตามนัด …"** · แนวทาง AI ขึ้น "ติดต่อผู้ปกครองทางเดิมยังไม่สำเร็จ — ลองทางอื่น" · นัดหมายมี 1 รายการ |
| A7 | แท็บ **ครอบครัวและทีม → บันทึกการเยี่ยมบ้าน** กด "กดเมื่อถึงบ้าน" · ผู้ร่วมพูดคุย **ผู้ปกครอง** · ผู้ดูแล **ปู่ย่าตายาย** · รายได้ **ต่ำกว่า 5,000** · อุปสรรค **ฐานะยากจน + เดินทางลำบาก** · เซ็นในกรอบ + ชื่อผู้ลงนาม → **บันทึกลงไทม์ไลน์** | ชิปเปลี่ยนเป็น **ได้รับความยินยอมแล้ว** · ข้อมูลครอบครัวแสดงครบ · สถานะ **กำลังช่วยเหลือ** · ผลล่าสุด ✓ ติดต่อผู้ปกครองได้แล้ว ✓ เยี่ยมบ้านแล้ว · นัดเยี่ยมบ้านหายจากรายการนัด |
| A8 | **แผนและการส่งต่อ → สร้างแผน** → เป้าหมาย **กลับเข้าโรงเรียนในระบบ** → **ถัดไป · ให้ AI แนะนำ** → **เริ่มดำเนินการ** | หน้าเส้นทางโอกาส: แผนเพิ่มเป็น 3 · เคสฮาฟิซเปิดขึ้นพร้อมขั้นถัดไป "ขอความเห็นชอบแผนจากครอบครัว" |
| A9 | **บันทึกว่าครอบครัวเห็นชอบ** | ขั้นถัดไปเปลี่ยนเป็นขั้นแรกของแผน |
| A10 | กลับหน้าข้อมูลเด็ก → แนวทาง **หาทุนค่าเดินทาง → ใช้แนวทางนี้** | หน้าส่งต่อเปิดขั้นตอนส่งต่อ: ด้าน **การเดินทาง** ถูกเลือกไว้แล้ว · เหตุผลมี "ครูพบว่า: ไม่มีค่ารถ…" |
| A11 | ถัดไป → AI แนะนำ **อบจ.ปัตตานี** → **เลือกหน่วยงานนี้** → ความพร้อม **✓ พร้อมส่ง** → ความยินยอม **✓ ยินยอมแล้ว** → ถัดไป → ถัดไป → ส่งเรื่องทาง **หนังสือ** → **บันทึกการส่งต่อ** | "✓ บันทึกการส่งต่อแล้ว" · แจ้ง อบจ. ทางหนังสือ · เกิน 24 ชม. ระบบเตือนให้โทรถาม |
| A12 | **ดูการส่งต่อนี้** → **อัปเดตความคืบหน้า** → **หน่วยงานรับเรื่องแล้ว** · เจ้าหน้าที่ "คุณอามีนะห์ ส." · ทาง **โทรศัพท์** → **บันทึกความคืบหน้า** | ขั้นถัดไป "… รับเรื่องแล้ว · คุณอามีนะห์ ส. — รอเริ่มดำเนินการ" · ขั้นที่ 2 จาก 5 ติ๊กพร้อมเวลา · โทรศัพท์ |
| A13 | **อัปเดตความคืบหน้า → ได้ผลแล้ว** (ได้รับทุน) → **บันทึกความคืบหน้า** | ขั้นถัดไป "ได้ผลแล้ว: ได้รับทุน/เงินสงเคราะห์แล้ว" ปุ่ม **ประเมินผล** · ขั้น "ดำเนินการ" ขึ้นว่า ข้ามขั้น |
| A14 | **ประเมินผล → ✓ ช่วยได้ — ปิดการส่งต่อ** | "ปิดการส่งต่อแล้ว" |
| A15 | กลับหน้าข้อมูลเด็ก ดูทุกแท็บ | ผลล่าสุด ✓ อบจ.: ได้รับทุน · ทีมมี **อบจ.ปัตตานี · คุณอามีนะห์ ส.** · **ไทม์ไลน์** มีครบ: สิ่งที่พบ → โทรไม่ติด → นัด → เยี่ยมบ้าน → แผน → ครอบครัวเห็นชอบ → ส่งต่อ (ทางหนังสือ) → รับเรื่อง (ทางโทรศัพท์) → ผลจาก อบจ. → ปิดการส่งต่อ |

## สถานการณ์ B — เด็กดีขึ้นแล้ว ปิดเคส

**เด็ก:** ฟาตีมะห์ ปะดอ (STD-0791) · ความเสี่ยงลด 74 → 57 · มาเรียน 100% · แต่ยังมีการส่งต่อเปิดอยู่ 3 รายการ

| # | ทำ | ต้องเห็น |
|---|---|---|
| B1 | **การช่วยเหลือ → ตัวกรอง "ใกล้ปิดเคส"** | ฟาตีมะห์ · ถัดไป "ดีขึ้นจนเกือบปิดได้ — รอผลจากบ้านพักเด็กฯ ก่อน" ปุ่ม **ดูการส่งต่อ** |
| B2 | **ดูการส่งต่อ** | ลิ้นชักการส่งต่อ "คุ้มครองเด็ก → บ้านพักเด็กฯ" + รายการ "ส่งต่อหน่วยงานอื่นของฟาตีมะห์ด้วย · 2" |
| B3 | สำหรับการส่งต่อแต่ละรายการ: **อัปเดตความคืบหน้า → ได้ผลแล้ว** → **ประเมินผล** → **✓ ช่วยได้** → เปิดรายการถัดไปจาก "ส่งต่อหน่วยงานอื่น…" ทำซ้ำจนครบ 3 | ทุกรายการ "ปิดการส่งต่อแล้ว" |
| B4 | หน้าข้อมูลเด็กของฟาตีมะห์ | สถานะ **พร้อมประเมินเพื่อปิดเคส** · แบนเนอร์ "ข้อมูลล่าสุดบ่งชี้ว่าเคสนี้อาจพร้อมประเมินเพื่อปิด" เหตุผลครบ 5 ข้อ ✓ ไม่มีการส่งต่อค้าง |
| B5 | **ประเมินเพื่อปิดเคส** → ติ๊ก "ได้คุยกับนักเรียนและครอบครัวแล้ว" → **ปิดเคส** | สถานะ **ปิดเคสแล้ว** · สิ่งที่ต้องทำต่อ "ปิดเคสแล้ว — ติดตามห่าง ๆ" · AI ไม่เสนอแนวทางเพิ่ม |
| B6 | ตรวจหน้าอื่น | เคสของฉัน: ฟาตีมะห์ไม่อยู่ในคิว · การช่วยเหลือ: อยู่ใน "ปิดเคสแล้ว" · เส้นทางโอกาส: อยู่ใน "ปิดเคสแล้ว" |
| B7 | (ไม่บังคับ) **เปิดเคสอีกครั้ง** | ประวัติเดิมทั้งหมดยังอยู่ สถานะกลับเป็นกำลังติดตาม |

## บั๊กที่เจอระหว่างทดสอบรอบนี้ (แก้แล้ว)

1. เยี่ยมบ้านแล้วนัดเยี่ยมบ้านไม่ปิด — ขั้นถัดไปยังบอก "รอเยี่ยมบ้านตามนัด"
2. เยี่ยมบ้านพบผู้ปกครองแล้ว สถานะยังเป็น "ติดต่อผู้ปกครองไม่ได้"
3. หลังเยี่ยมบ้านครั้งแรก ไม่มีปุ่มบันทึกการเยี่ยมครั้งถัดไป
4. "ผลล่าสุด" แสดงการโทรครั้งก่อนแทนการเยี่ยมบ้านที่เพิ่งบันทึก
5. ขั้นแนะนำของแผนให้เหตุผล "คะแนนด้านสุขภาวะ 18/100" ซึ่งเป็นความเสี่ยงต่ำ (ขัดกันเอง)
6. เลือกแนวทาง "หาทุนค่าเดินทาง" แล้วฟอร์มส่งต่อไม่เลือกด้านการเดินทางให้ และเหตุผลอ้างสาเหตุที่ไม่เกี่ยวข้อง

## ข้อจำกัดที่ยังอยู่

- คะแนนความเสี่ยงไม่เปลี่ยนตามการช่วยเหลือในเดโม (ต้องมีข้อมูลการมาเรียนใหม่)
- ยังไม่ต่อระบบหน่วยงาน — ความคืบหน้าของหน่วยงานมาจากที่ครูบันทึกเอง
- ข้อมูลที่บันทึกเก็บในเบราว์เซอร์เครื่องนั้น — เปลี่ยนเครื่องหรือเบราว์เซอร์จะไม่เห็น
- เด็กชื่อซ้ำ (เช่น ปิยะดา ลาเตะ 2 คน) เคสถูกจับคู่ด้วยชื่อ อาจได้ตัวเลข SLA ของอีกคน
