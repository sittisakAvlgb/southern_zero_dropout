# โต๊ะทำงานรายเด็ก (ข้อมูลเด็กรายบุคคล · ครู)

> **"ครูรู้ปัญหา — AI ช่วยหาวิธี"** · AI เป็น Decision Support ไม่ใช่ Decision Maker · การตัดสินใจสุดท้ายเป็นของครูเสมอ

`/student` ของบัญชีครูเปิด `TeacherStudentDesk` บทบาทอื่นยังเห็นแฟ้มข้อมูลเดิม (`Student360`) — สลับที่ `components/student/StudentRoute.tsx`

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `src/lib/careOps.ts` | ทางเลือกที่ AI เสนอ (เหตุผล · ข้อดี · ข้อควรพิจารณา · ข้อมูลที่ใช้) · ทางเลือกเมื่อทางเดิมไม่ได้ผล · สถานะเคสภาษาคน · แนวโน้ม · เป้าหมายที่เสนอ · ผลล่าสุด · ทีม |
| `src/lib/followOps.ts` | "สิ่งที่ต้องทำต่อ" + เหตุผลที่ต้องดู — ตัวเดียวกับหน้าติดตามการช่วยเหลือ |
| `src/lib/caseLog.ts` | เพิ่ม `observations` (สิ่งที่ครูพบ) · `goals` · `choice` ในบันทึก (ครูเลือก/ปรับ/ไม่ใช้ข้อเสนอ) |
| `src/components/student/TeacherStudentDesk.tsx` | หน้าจอ |
| `src/components/followup/*` | แผ่นงานบันทึกผล/นัด/ปิดเคส/ถาม AI และไทม์ไลน์ ใช้ร่วมกับหน้าติดตาม |
| `src/pages/Student360.tsx` | export `LogForm` เพื่อใช้ฟอร์มเยี่ยมบ้านเต็มรูปแบบ (ลายเซ็น · ครอบครัว · ความยินยอม) ตัวเดิม |

## Flow

```
ครูเข้าใจปัญหา → บันทึกสิ่งที่พบ → ดูข้อมูลประกอบ → AI เสนอแนวทาง (พร้อมเหตุผล)
→ ครูเลือก / ปรับ / ไม่ใช้ → ลงมือ → บันทึกผล → ไทม์ไลน์อัปเดต
→ AI อ่านผลใหม่ (เช่น โทรไม่ติด) แล้วเสนอทางอื่น → ครูเลือก Next Action → ติดตาม / ส่งต่อ / ปิด
```

## ลำดับบนหน้า (มือถือและจอใหญ่ลำดับเดียวกัน)

1. **เด็กคนนี้เป็นใคร** — ชื่อ · ชั้น · โรงเรียน · ครูเจ้าของเคส · สถานะเคส · คะแนน + ระดับ + "↑ เพิ่มขึ้น X คะแนนจากสัปดาห์ก่อน" (ไม่มีคะแนนโดด ๆ)
2. แบนเนอร์ "อาจพร้อมประเมินเพื่อปิด" / "ปิดเคสแล้ว — เปิดอีกครั้งได้" (เมื่อเกี่ยวข้อง)
3. **สิ่งที่ครูพบ** — เพิ่ม · แก้ไข · คลี่คลายแล้ว · "ข้อมูลในระบบบอกว่า… ตรงกับที่ครูเห็นไหม?" กดยืนยันได้ (ระบบไม่ใส่ให้เอง)
4. **ต้องติดตามตอนนี้ เพราะ** + **สิ่งที่ต้องทำต่อ** (เด่นที่สุด) · เหตุผล · [ปุ่มตามงานจริง] [ดูทางเลือกอื่น] [ถาม AI]
5. **แนวทางที่อาจช่วยได้** — 3 ทาง (ดูเพิ่มได้) แต่ละทางมี เพราะ · ข้อดี · ข้อควรพิจารณา · [เลือกแนวทางนี้] [ปรับแนวทาง] [ไม่ใช้คำแนะนำ] + **"AI แนะนำจากข้อมูลเหล่านี้"**
6. **นัดหมาย / สิ่งที่จะทำต่อ** — วัน เวลา วิธี ผู้รับผิดชอบ
7. **ผลล่าสุด** — ✓ / ○
8. **เป้าหมาย 30 วัน** — AI เสนอ ครูแก้/ยืนยัน · ข้อที่วัดได้ระบบวัดให้ (มาเรียน % · ติดต่อผู้ปกครอง · เยี่ยมบ้าน · คะแนน) ที่เหลือครูติ๊ก
9. **บันทึกสั้น** → ไทม์ไลน์ + AI ใช้ครั้งถัดไป
10. **ไทม์ไลน์การช่วยเหลือ** — บันทึกครู · นัด · เยี่ยมบ้าน · การเลือกแนวทาง · การส่งต่อและหน่วยงานตอบรับ · ความเสี่ยงเปลี่ยน · ปิด/เปิดเคส
11. **แนวโน้มความเสี่ยง** — 4 สัปดาห์เป็นตัวเลข + ข้อสังเกตหนึ่งประโยค (ไม่ใช่กราฟ)
12. **ทีมที่กำลังช่วย** — เฉพาะที่เกี่ยวข้องจริงจากบันทึก
13. **งานที่เกี่ยวข้อง** — สถานะของงาน (แผน · ส่งต่อ · ติดตาม · เยี่ยมบ้าน) พร้อมปุ่ม
14. ข้อมูลเพิ่มเติม (พับไว้)

มือถือ: ปุ่ม "เปลี่ยนนักเรียน" ด้านบน · แถบติดล่าง [บันทึกผล] [เพิ่ม Note] [ถาม AI] · จอใหญ่: รายชื่อด้านซ้ายเรียงตามความเร่งด่วน

## AI ทำอะไร — และไม่ทำอะไร

- **ภาษา**: "แนวทางที่อาจช่วยได้" · "อาจพิจารณา" · "AI เสนอทางเลือก — ครูเป็นผู้ตัดสินใจ" ไม่มีคำสั่ง
- **อ่านสิ่งที่ครูเขียน**: ครูบันทึก "ไม่มีค่ารถ" → ทางเลือกเรื่องค่าเดินทางขึ้นอันดับหนึ่ง และบอกว่า "ครูบันทึกว่ามีปัญหาค่าเดินทาง" · ครูเขียนว่าเด็ก "เงียบ/ซึม" → นัดครูแนะแนวขึ้นมา
- **ทางเดิมไม่ได้ผล**: บันทึก "ติดต่อไม่ได้" → แถบ "แนวทางเดิมยังไม่ได้ผล" + ทางใหม่ (ญาติ/ผู้ดูแลอื่น · เยี่ยมบ้าน · ทีมโรงเรียน)
- **ไม่เสนอซ้ำ**: ทางที่ครูนัดไว้แล้ว และทางที่ครูกด "ไม่ใช้" (พร้อมเหตุผล) — เก็บใน `choice` จึงคงอยู่หลังรีโหลดและตรวจย้อนได้
- **ไม่ปิดเคสเอง**: บอกว่า "อาจพร้อม" + เหตุผล ครูต้องประเมินและยืนยัน

## กติกาที่ตามมา

- การเลือก/ปฏิเสธข้อเสนอ AI, การนัด, Escalate **ไม่นับเป็นการอัปเดตเคส** (`isScheduleOnly`) — SLA เคลียร์ได้ด้วยการลงมือจริงเท่านั้น
- บันทึกผลจะปิดเฉพาะนัดที่เป็นเรื่องเดียวกัน — โทรไม่ติดไม่ได้แปลว่านัดประสานผู้นำชุมชนเสร็จ (บั๊กที่เจอระหว่างทดสอบ)
- สถานะ "พร้อมประเมินเพื่อปิดเคส" ขึ้นเมื่อไม่มีการส่งต่อเปิดอยู่เท่านั้น

## Scenario ที่ทดสอบแล้ว

1. เปิดเด็ก → ยืนยันสิ่งที่พบจากข้อเสนอ + พิมพ์ "ไม่มีค่ารถ…" → AI เปลี่ยนอันดับ → เลือก "ประสานผู้นำชุมชน" → นัด (วิธีเลือกไว้ให้) → ไทม์ไลน์มีทั้งการเลือกและนัด
2. กลับมาอีกครั้ง → ผลล่าสุด + นัดที่ค้าง + สิ่งที่ต้องทำต่อตามสถานะใหม่
3. บันทึก "ติดต่อไม่ได้" → นัดผู้นำชุมชนยังอยู่ → AI: "แนวทางเดิมยังไม่ได้ผล" + ทางเลือกใหม่ → สิ่งที่ต้องทำต่อเปลี่ยนเป็นนัดเยี่ยมบ้าน
4. เด็กที่ดีขึ้น (74 → 57) → แบนเนอร์อาจพร้อมปิด + เหตุผล + ○ การส่งต่อที่ยังเปิด → ประเมินเพื่อปิด (ครูตัดสินใจ)

เพิ่มเติม: ไม่ใช้คำแนะนำ + เหตุผล คงอยู่หลังรีโหลด · ยืนยันเป้าหมายแล้ววัดให้อัตโนมัติ · 375px ไม่ล้นจอ แถบติดล่างอยู่เหนือเมนูล่าง

## สถานะ

Loading (skeleton) · AI processing ("AI กำลังคิดทางเลือกจากข้อมูลล่าสุด…") · Empty (ไม่มีนักเรียน / ยังไม่มีสิ่งที่ครูพบ / ยังไม่มีนัด) · Error ("ไม่สามารถโหลดข้อมูลนักเรียนได้" + ลองอีกครั้ง) · Success (toast ทุกการบันทึก)

## ยังไม่ได้ทำ / ข้อจำกัด

- "ถาม AI" เป็นคำถามสำเร็จรูปที่ตอบจากข้อมูลในเครื่อง ยังไม่ส่งสิ่งที่ครูพบเข้า `/api/chat`
- เป้าหมายข้อ "พบครูแนะแนว 2 ครั้ง" ยังนับอัตโนมัติไม่ได้ ครูติ๊กเอง
- ทีม: อนุมานจากข้อความในบันทึก (เช่น มีคำว่า "ผู้นำชุมชน") ยังไม่มีการเพิ่มสมาชิกทีมโดยตรง
- `Student360.tsx` ของบทบาทอื่นถูกแตะสองจุด (export `LogForm`/`LogResult`) — น้องที่ทำ `feat/student-detail` อาจเจอ conflict เล็ก ๆ ตรงนั้น
