# บรีฟ / สเปกวิดีโอ PR — Southern Zero Dropout Platform

> **หมายเหตุ:** วิดีโอนี้ไม่ได้สร้างจาก "prompt" ป้อนให้ AI generate วิดีโอ
> แต่สร้างด้วย **Remotion (React/TypeScript)** + **ภาพหน้าจอจริงของแพลตฟอร์ม** + **เพลงประกอบ**
> เอกสารนี้คือ "บรีฟต้นทาง" ที่นิยามวิดีโอทั้งเรื่อง — ใช้เป็นสเปกเพื่อสร้างใหม่ ปรับ หรือส่งต่อได้
> ข้อความบนจอทั้งหมดอยู่ใน `out/sbp-pr-film.th.srt` · โครงสร้างจริงอยู่ใน `src/timeline.mjs`

## 2. สไตล์ & หลักการเล่าเรื่อง

- **โทนสี:** navy เข้ม (`#0B1736`) เป็นพื้น · ทองอุ่น (`#F2C66D`) เป็นสีเน้น · teal/royal เป็น accent
- **ฟอนต์:** Bai Jamjuree (หัวเรื่อง) · Noto Sans Thai Looped (เนื้อความ) — ชุดเดียวกับในแอป
- **หน้าจอจริงเท่านั้น ไม่แต่งภาพ** · ภาพห้องเรียน/โรงเรียนเป็นภาพประกอบ (SVG)
- **หลักการสำคัญ (โจทย์จาก CEO):**
  1. **"เห็นขั้นตอนการใช้งานจริง ไม่ใช่ภาพนิ่งแว้บไปมา"** → หน้าต่างเบราว์เซอร์ **ล็อกนิ่งทั้งบานตลอด role** · **เคอร์เซอร์เดินไปกดปุ่มจริงทีละขั้น** แล้วหน้าจอ crossfade ไปขั้นถัดไป · มีตัวนับ "ขั้น N/ทั้งหมด" · ดึงสายตาด้วยกรอบทอง+หรี่รอบข้าง ไม่ใช่การซูมกระโดด
  2. **เน้นผู้ช่วย AI** — โชว์ชัดว่า AI อ่านสาเหตุรายคนแล้วเสนอวิธีช่วยพร้อมเหตุผล
  3. **เปิดด้วยบรรยากาศโรงเรียนกลางวันจริง** (ฟ้าใส · เด็กเล่นบอล · ธงชาติ · มะพร้าว) แล้วซูมเข้าห้องเรียน

## 3. ข้อจำกัดที่ต้องรักษา (PDPA / ความถูกต้อง)

- **ชื่อเด็กทุกคน = นามสมมติ** ("นักเรียน ก., ข., ค., …" เด็กตัวเดินเรื่อง = "ก." เสมอ)
- **ชื่อโรงเรียนจริง = "โรงเรียนสาธิต N"** (เพราะตัวเลขความเสี่ยงเป็นข้อมูลจำลอง)
- **ชื่อบุคลากร/บัญชีสาธิตคงไว้** (เป็นตัวละครสมมติอยู่แล้ว เช่น ครูนูรียะ, ศึกษานิเทศก์อารีฟิน)
- **ชื่ออำเภอ/จังหวัดคงไว้** (ข้อมูลภูมิศาสตร์สาธารณะ ไม่ใช่ข้อมูลเด็ก)
- **ขอบเขต = 3 จังหวัดชายแดนใต้** (ปัตตานี · ยะลา · นราธิวาส = 9 เขตพื้นที่) ไม่มีระดับประเทศ
- ตัวเลขทั้งหมดเป็น **ข้อมูลจำลองเพื่อสาธิต** ยังไม่ใช่ผลการใช้งานจริง

## 4. โครงสร้างฉากทั้งหมด (พร้อมข้อความบนจอ)

### เปิดเรื่อง
1. **โรงเรียนกลางวัน** (SVG แอนิเมชัน ~7.5s) — ฟ้าใสเมฆขาว · อาคารขาว-ฟ้า · ธงชาติ · มะพร้าว · เด็กเล่นฟุตบอล · ทางเดินมีกระถางดอกไม้ → กล้องซูมเข้าหน้าต่างห้องเรียน จอมืดลง
   *"ทุกเช้า ในโรงเรียนทั่วสามจังหวัดชายแดนใต้ · ห้องเรียนเริ่มต้นขึ้นอีกวัน"*
2. **ห้องเรียน เก้าอี้ว่าง** — *"เด็กหนึ่งคนที่หายไปจากห้องเรียน... อาจกำลังรอโอกาสจากใครสักคน"*
3. **สัญญาณกระจาย** — *"สัญญาณมีอยู่แล้ว · แต่กระจายอยู่หลายที่ จนไม่มีใครเห็นทั้งภาพ"* (ป้ายสัญญาณ: ขาดเรียน 16 วัน · เกรด 0.80 · รายได้ 5,000/เดือน · เลยนัด 14 วัน · ความเสี่ยง +13 · ส่งต่อแล้วแต่ยังไม่ตอบรับ)
4. **โลโก้** — *"Southern Zero Dropout Platform · ทุกการช่วยเหลือ เริ่มต้นจากการมองเห็น"*
5. **เส้นทาง 4 ระดับ** — *"ติดตามเคสจำลองหนึ่งเคส · ผ่านหน้าจอจริงทั้ง 4 ระดับ — โดยมี AI ช่วยครูหาวิธีช่วยเหลือรายคน"*

### บท 01 · ครู (7 ขั้น — หน้าจอจริง + เน้น AI)
1. เคสของฉัน — *ครูเปิดงานจากคิวที่ระบบจัดให้* → **กดเปิดแฟ้มเด็ก**
2. ข้อมูลเด็กรายบุคคล — *เปิดเคสแล้วเห็นสาเหตุ ไม่ใช่แค่คะแนน* (เน้นคะแนนเสี่ยง 77)
3. **AI: แนวทางที่อาจช่วยได้** — *AI อ่านสาเหตุรายคน แล้วเสนอวิธีช่วยเป็นขั้น · ทุกข้อมีเหตุผลจากข้อมูลเด็กคนนี้* (สอนเสริม·เกรด 0.80 / ยืมอุปกรณ์ / นัดครูแนะแนว·ขาด 16 วัน)
4. **ถาม AI** — *ถาม AI ต่อได้ — ตอบจากข้อมูลของเคสนี้* (ทำไมเสี่ยง · ช่วยอะไรไปแล้ว · ควรส่งต่อใคร → "สาธารณสุข · พมจ./ท้องถิ่น")
5. บันทึกการช่วยเหลือ — *สิ่งที่ครูเห็นเอง ป้อนกลับให้ AI*
6. ขอการสนับสนุนจาก ผอ. — *งานที่เกินกำลังครู ส่งถึง ผอ. ได้ทันที* → **กดส่งคำขอ**
7. ส่งคำขอถึง ผอ. แล้ว ✓ — *ครูยังเป็นผู้ดูแลเคส · ผอ. เป็นผู้ตัดสินใจ*

### บท 02 · ผอ.สถานศึกษา (4 ขั้น)
1. ภาพรวมโรงเรียน — *คำขอของครูขึ้นเป็นเรื่องแรกที่ ผอ. ต้องตัดสินใจ* → **กดพิจารณาคำขอ**
2. พิจารณาคำขอ — *เปิดคำขอ เห็นสิ่งที่ครูทำมาแล้ว* → **กดยกระดับไปเขต**
3. ตัดสินใจ — *อนุมัติ · มอบหมาย · หรือยกระดับถึงเขต* → **กดยืนยันและส่งงานถึงครู**
4. ส่งงานถึงครู และส่งเรื่องถึงเขต ในครั้งเดียว ✓

### บท 03 · เขตพื้นที่การศึกษา (5 ขั้น)
1. ภาพรวมเขต — *เห็นพื้นที่เสี่ยง และคำขอจากโรงเรียนที่เข้ามาวันนี้* → **กดคำขอ**
2. คำขอจากโรงเรียน — *เห็นสิ่งที่โรงเรียนทำแล้ว และสิ่งที่ยังติดอยู่* → **กดตัดสินใจตามนี้**
3. ตัดสินใจ · เขต — *เขตจัดทีมสนับสนุน ตามภาระงานจริงของทีม · AI แนะนำ คนเป็นผู้ตัดสินใจ* → **กดส่งถึง ผอ.**
4. ส่งทีมสนับสนุนกลับถึงโรงเรียนแล้ว ✓
5. โรงเรียนในเขต — *ติดตามทุกโรงเรียนในเขตอย่างต่อเนื่อง · เรียงตามความจำเป็น*

### บท 04 · ผู้บริหาร สพฐ. (อ่านอย่างเดียว · 2 ขั้น)
- **แผนที่ 3 จังหวัด** — ปัตตานี • ยะลา • นราธิวาส · 33 อำเภอ · 46 โรงเรียนนำร่อง
1. ภาพรวมชายแดนใต้ (dashboard รายเขต) — *ข้อมูลจากงานประจำวันของครู กลายเป็นภาพรวมเชิงนโยบาย · เห็นครบทุกเขตพื้นที่ · AI สรุปเรื่องที่ควรจัดการวันนี้* (เน้นกล่อง "AI สรุปวันนี้ 5 เรื่อง")
2. แผนที่และเจาะลึกพื้นที่ — *เจาะลงรายพื้นที่ด้วยแผนที่ · สัดส่วนเสี่ยง · เด็กนอกระบบ · แนวโน้มความเสี่ยง 12 เดือน รายเขต/อำเภอ*

### ปิดเรื่อง
- **วงเชื่อมเคส** — *"ไม่ใช่แค่การเก็บข้อมูล · แต่คือการเชื่อมทุกความช่วยเหลือ"* → การ์ดเคสเดินทางครบ 4 ระดับ แล้วย้อนกลับลงมาถึงครู
- **ย้อนถึงครู** — *คำตอบย้อนกลับมาถึงครู เป็นงานถัดไปที่ชัดเจน · นัดทีมเยี่ยมบ้านภายใน 3 วัน เพราะ ผอ. อนุมัติแล้ว*
- **ห้องเรียน เก้าอี้มีคนนั่งแล้ว** — *"เพื่อโอกาสของเด็กทุกคน"*
- **ข้อเสนอนำร่อง** — 3 ขั้น (เริ่มที่โรงเรียนนำร่อง → เปิดวงกับเขต → สรุปผลให้ สพฐ.) + หมายเหตุ PDPA/DMC
- **ปิดท้าย + QR** — *"มองเห็นทุกคน ออกแบบโอกาสเฉพาะบุคคล"* · QR ไปเว็บต้นแบบ · เครดิตเพลง "The Epic Hero" โดย Keys of Moon

## 5. วิธีสร้าง (pipeline)

```bash
# 1) เปิดแอปที่ราก repo (สคริปต์จับภาพใช้ http://localhost:5173)
npm run dev

# 2) ในโฟลเดอร์ video/
npm install
npm run capture          # เปิด Chrome จริง เดิน workflow ครู→ผอ.→เขต→สพฐ.→กลับถึงครู
                         #   จับภาพหน้าจอจริง + บันทึกพิกัดปุ่มที่เคอร์เซอร์ต้องกด (src/boxes.json)
npm run prepare-assets   # แผนที่ · QR · เสียง UI · ไฟล์ SRT
npm run studio           # ดู/ปรับในเบราว์เซอร์ (ไม่บังคับ)
npm run render           # → out/sbp-pr-film.mp4
```

- **แหล่งความจริงเดียว:** `src/timeline.mjs` — ลำดับฉาก ข้อความ เวลา และ "ขั้น" ของแต่ละ role
- **ตัว render ของ journey:** `src/walk.tsx` (หน้าต่างล็อก + เคอร์เซอร์ + crossfade) · ฉากประกอบ `src/story.tsx`
- **หน้าจอทั้งหมด capture จาก branch `main`** (UI ล่าสุด) · ต้องมี Chrome ที่ `C:/Program Files/Google/Chrome/Application/chrome.exe`
- **ตรรกะ AI ที่ขึ้นจอ** มาจาก `src/lib/recommend.ts` จริง (คำนวณจากข้อมูลเด็ก ไม่ได้แต่ง)
